# 备份与恢复：完整操作设计台账

本页从 `SOURCE-DISCOVERY.md`、设计 README、DESIGN、src/AGENTS 以及 typography、color、accessibility-baseline、form-validation、state-coverage、animation-discipline 逐项审查。保留 Git 备份业务和原有备份范围，不把原项目的工程命令搬入本项目。

## 功能和操作矩阵

| 入口 / 操作 | 状态与反馈 | 动效 / 公共实现 | 本轮实改 |
| --- | --- | --- | --- |
| 备份页状态 / 刷新 | 未连接、待同步、本地或远端更新、已同步、读取失败 | PageHeader、Button；稳定状态区 | 状态请求有忙碌标记；读取失败显式重试，不再无限加载 |
| 手填远端 / 保存 | 未改、编辑、保存中、错误、成功 | 原生带标签输入、共享按钮 | 可见标签；保存时锁定；就近错误保留输入；避免与同步/恢复竞争 |
| 开始备份 / 从远端恢复 / 初始化本地 | 未选远端禁用、选择、进行中、失败可重试、成功关闭 | GitSetupDialog → DetailSheet；选择卡保留原生按钮 | 捕获原回调异常，不再未处理 rejection；持久错误与状态播报；忙碌禁止关闭 |
| GitHub 浏览器连接 | 发起、验证码、等待、取消、过期、拒绝、网络错误、连接成功 | 共享按钮；外部授权保持现有逻辑 | 取消后新轮询用代号隔离旧响应；卸载不会污染新轮询；复制成功等到真实剪贴板写入后显示 |
| GitHub PAT 连接 | 输入 token / 仓库名、提交、错误与重试 | 密码输入、可见标签、共享按钮 | token / repo 有可见标签；错误 role=alert 关联输入；保留原鉴权逻辑 |
| 手动备份 / 重试 / 重新连接 | 进行中、同步结果、部分冲突、失败、认证失效 | 统一按钮和常驻 polite 状态区 | 恢复、同步、保存远端、冲突操作统一互斥 |
| 自动备份开关 / 后台完成事件 | 开关保存中、成功、失败；后台完成刷新 | ToggleSwitch；现有自动状态监听 | 处理器补充防重复；保留后台完成刷新技能/预设和错误逻辑 |
| 设备名称编辑 / Enter 保存 / Escape 取消 | 编辑、保存中、失败、成功 | 原生输入和共享按钮 | 失败不再提前关闭编辑；保留草稿、就近错误；空值禁用；保存中禁止 Escape |
| 历史版本刷新 / 空历史 | 加载、真实空、列表、失败可重试 | 紧凑列表与共享按钮 | 获取失败不再伪装成空历史；保留已有列表数据与显式重试 |
| 恢复指定版本 / 取消 | 确认、恢复中、成功、安全快照、失败 | ConfirmDialog → DetailSheet | 失败抛回确认组件保留对话框与重试；其他写操作禁用 |
| 冲突：保留本地 / 使用远端 / 两者保留 | 冲突列表、处理中、安全版本、失败 | 共享按钮和状态提示 | 获取失败显式提示并可重试；处理期间阻止其他写操作 |
| 仓库修复 / 重新克隆 | 原因解释、执行中、失败、成功 | GitRecoveryDialog → DetailSheet | 明确捕获异常及持久错误；可重试；忙碌不可关闭 |
| 断开本机 / 撤销授权 | 二次确认、执行中、失败、成功 | ConfirmDialog、Button | 断开失败保留确认界面；撤销入口保留原外部授权页面路径 |
| 前往删除远端仓库 | 二次确认、浏览器打开失败或成功 | ConfirmDialog；外部仓库仍由 GitHub 确认 | 不再吞掉浏览器打开失败后报“已打开” |
| 首次空库恢复 / 从空白开始 | URL 输入、恢复中、失败重试、成功、关闭 | FirstRunRestoreDialog → DetailSheet | 不提前卸载，保留退出动画；URL 错误描述关联；状态播报、防重复 |
| 备份范围 / 体积 / 汇总 | 包含与排除说明、体积提示、技能及快照总数 | token 面板、标题层级 | 保留现有信息语义，不虚构备份内容 |

## 非本页功能边界

备份页没有独立 ZIP 导入/导出功能；本地/Git 技能导入在发现技能页，预设 JSON 导入/导出在维护/预设界面，由对应任务覆盖。不能把远端 clone 宣称为所有格式导入已验收。

## 验证与交付边界

- 已运行责任文件的 ESLint，无错误。
- `npx tsc -b` 已通过（共享 Disclosure 创建完成后重跑）；责任文件 `git diff --check` 通过。全量打包由主任务统一执行。
- 本轮未执行真实 GitHub 连接、备份、恢复、撤销、远端删除，未修改用户远端或备份数据。
- 已消费共享 LoadingState，为状态请求、写操作、版本加载和三个 Git/首次恢复对话框提供慢请求说明。
- 原生界面验收、隔离目录数据写入验证及共享组件的超时/减少动态效果验收由主任务集中执行；上述源码修复不能等同于相关网络分支全部实机验收。
- OAuth/PAT 在线成功、权限撤销、双设备真实冲突、慢网络超时需集成环境，不能以代码存在宣布已覆盖。
