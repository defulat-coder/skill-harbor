# 设置与工具控制交付矩阵

本轮范围：`Settings.tsx`、`RunnerSettings.tsx`、`AgentControlSetupCard.tsx`、`AgentToggleSection.tsx` 及同名 CSS Module。只改变前端的呈现、状态管理及错误恢复；后端命令及设置键保持原有协议。未向真实用户设置写入数据。

依据：根/src AGENTS、DESIGN、docs/design/README 与 SOURCE-DISCOVERY；craft 的 typography、color、accessibility-baseline、state-coverage、form-validation、animation-discipline。OpenDesign SettingsDialog 的分类方式映射到本地技能管理场景；所有普通项目添加仍为软链接。

验证标记：**静态** = 实际执行 TypeScript 编译、定向 ESLint 加源码审查；不等于后台命令或界面状态已实际执行。**UI 待集成** = 交给统一隔离数据验收，不以源码存在冒充点击验收。

## 材质、动效、边界

局部布局归入四个 CSS Module，消费已有 ds token，不新增配色体系。按钮、Disclosure、DetailSheet 的悬停/焦点/进出/减动效由共享组件提供；分类切换仅200ms透明度提示，减少动态效果下关闭。路径不改写，长错误允许换行，工具操作不依赖鼠标悬停。

## Impeccable 第 3 轮：维护页面减噪

本轮只改五个页面，未扩展共享控件，也未改后端 API。

- Settings：删除页面上重复的通用介绍和主题/字号的自明说明；保留目录影响、关闭行为、同步模式等会影响决定的提示。
- MySkills：检查更新成为明确主动作；只有存在更新或更新进行中才显示批量更新；Git 状态降为轻量辅助链接；来源与标签收进同一个公共 Disclosure，标题显示已选条件数，标签管理及筛选值保留。
- Backup：备份范围说明默认折叠，超大文件等警告仍在折叠外；自动备份、断开/撤销/删除连接及汇总收进“备份设置与连接管理”。当前同步状态、恢复异常、历史记录和全部破坏操作确认保留。
- WorkspaceView：刷新移出视图选择分段；标签筛选按需展开并显示条件数；低频移除/删除收进公共条目菜单，差异状态的上传/拉取动作仍直接可见，调用和确认不变。
- ProjectDetail 高级页：去掉重复页标题容器并将搜索工具条自然左对齐；删除常驻首次添加气泡及其单独的提示存储状态；添加技能功能和现有弹窗说明保留；标签筛选默认折叠。

实际检查：五页面定向 ESLint 与 `npx tsc -b` 均通过。尚未实际验证原生窗口展开后的视觉、菜单边界、隔离目录写入和后端异常；交给第 4 轮统一视觉复审。该记录不把静态检查当成端到端验收。
