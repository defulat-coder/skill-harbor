# 预设管理与标签表单交付

实现：PresetManager（受控 `open` / `onClose`），复用 DetailSheet、Button、CardActionMenu、CreatePresetDialog、RenamePresetDialog、ConfirmDialog。入口由公共侧栏接入。预设只组织全局技能，不改变项目软链接机制。

## 操作与行为

- 创建：名称、说明、图标；成功刷新预设和技能；失败保留输入并播报错误。
- 查看：设置 viewedPresetId 后前往维护与更新；沿用旧 Sidebar 的“查看不自动应用”语义。
- 编辑：名称、图标；保留原说明；无变化不提交。
- 删除：确认分组名后删除预设关系，全球技能文件保留；后端失败时确认仍在。
- 上移/下移：完整 ID 顺序提交原 reorderPresets API；边界按钮禁用；保存失败展示错误，不乐观伪造成功顺序。
- 空列表：提供新建入口和说明；长名称/描述可换行，行内操作保持独立。
- 四种编辑表单：受控 open 保持挂载以交给公共模态退出；同步 ref 防同帧重复提交，字段和关闭按钮 busy 锁，所有 Promise 拒绝捕获，输入保留。中文输入法组合期间 Enter 不提交。
- 批量标签建议改为表单内原生按钮区，避免另造脱离模态焦点层级的浮层；删除标签标记保留 aria-pressed。
