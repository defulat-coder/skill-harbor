# 完整设计与端到端交付目标

状态：本机设计交付完成（2026-09-05）。独立任务并行实施，公共组件统一集成；验收范围和外部服务限制见 verification.md。完成不等于所有平台、所有外部服务均已人工测试。

## 目标

依据已迁入的 OpenDesign 原文规则，对现有项目全部可达功能、页面、弹窗、操作及动效建立可核对清单并完整审查/重设计。全局维护技能 → 中文用法/原文 → 项目软链接为核心不变量；原有管理能力不能因重设计失去入口。

## 工作包

1. 功能清单与可达性：路由、组件调用、所有操作/状态/动效，识别遗漏和不可达旧功能。
2. 公共系统：布局、按钮、表单、模态、折叠、菜单、快捷搜索、主题、点阵、焦点与减少动态效果。
3. 全局技能与维护：浏览筛选、标签/预设、批量、更新、工具启停、差异与来源。
4. 项目与执行：新建/导入/移除/排序、链接/解除、高级管理、运行/停止/历史/日志。
5. 发现与中文：市场、本地、Git、搜索转换、导入进度、中文生成/编辑/过期/失败。
6. 设置与备份：逐项设置、路径、权限提示、连接/备份/恢复/冲突/失败。
7. 项目链接契约：审查所有普通项目添加入口，阻止复制回退，保留旧副本读取兼容。
8. 集成验收：完整类型/lint/适当测试；隔离目录真实用户流程；明暗/键盘/动效/异常；本机包与签名、操作记录。

## 完成标准

- 每个注册页面和每类可达操作都有盘点记录、设计决定和验证状态，不以“组件已存在”代替验收。
- 规则不符合项已修复或有明确产品理由；不可达但需要保留的功能重新提供入口。
- 加载、首次空、筛选无结果、错误/重试、成功/部分成功、忙碌禁用、长内容均明确处理。
- 普通项目添加严格软链接，不覆盖同名非托管数据；移除登记不删除项目目录。
- 共享交互有键盘/焦点语义；减少动态效果有效，关闭/折叠没有焦点滞留。
- 自动检查通过，真实回归与受限操作明确区分。使用临时技能/项目/本地Git测试仓库，不对用户真实数据执行验收写入。
- 交付可运行macOS应用、逐项清单及证据；其他平台和外部服务受限项如实记录。
