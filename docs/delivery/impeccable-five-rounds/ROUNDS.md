# 五轮执行记录

## 第1轮：信息结构

发现：侧栏“添加技能”和“发现技能”同目的重复；索引、维护、预设与日常场景平铺；底部工具目录、备份与设置并列；新建项目与项目列表重复入口。原项目 EntryNavRail 明确侧栏只作导航，最近项目可折叠，管理项按需展开。

修改：删除重复的全局添加按钮，保留日常四个入口和独立索引；管理功能归入“更多管理”；最近项目采用折叠分组，创建在项目页发起。全部原路由保留。

验证：npm run lint、npm run build 通过；所有原管理路由保留，原生Disclosure保证折叠后键盘不会进入隐藏内容。

## 第2轮：主要任务

发现：技能库默认呈现全选、每卡勾选及加入动作；同一技能在检索结果按片段重复出现8次时，会重复展示8个加入按钮。市场/导入和项目页的动作层级也混杂。

修改：技能库多选按需开启，筛选排序按需展开，卡片专注阅读、在详情加入项目；检索按技能合并来源，引用编号不变；市场与项目子范围并行调整。

验证：npm run lint、npm run build 通过。市场保留安装、取消、来源过滤和各导入API；项目保留更多菜单内的发现/高级入口；引用编号继续对应原始候选顺序。

## 第3轮：渐进披露

复查第二轮：主要场景已减少按钮，但索引页面仍重复呈现标题、环境与常驻刷新；中文说明同时呈现编辑/重生成；维护、设置、备份仍有多层重复说明。

修改：索引只保留构建为主动作、成功后开始提问，环境检查放详情；中文说明低频操作移入选项。维护和高级管理子范围并行精简。

验证：npm run lint、npm run build 通过；五个管理页各自也通过定向 ESLint/TypeScript；所有原API及破坏操作确认保留。

## 第4轮：状态与交互

复查第三轮：从搜索结果阅读技能后返回，会丢失问题/回答；侧栏快捷项目未保护长名称；项目列表标题重复。

修改：当前目录的问答状态在应用会话内保留，换目录隔离；未完成回答可单独继续整理；快捷项目长名省略显示并保留完整title；统一项目命名，去除重复标题。安排对改后市场/项目功能的独立回归审查。

验证：定向 ESLint/TypeScript 通过；最终完整lint/build与桌面包正在检查。

第4轮补充复审发现：市场切换过滤后会丢失安装取消入口、忙碌时可更改目标导致显示与实际目标错位；维护标签菜单位于折叠区，被容器裁切。相应修复：固定安装状态/取消入口、冻结忙碌目标、共享Disclosure展开结束后允许菜单溢出，折叠时继续裁切。

验证：进行中。

第5轮实际走查补充：真实中文查询返回3个技能/8条来源，编号保持正确。观察到回答正文仍重复列出完整路径，且阅读/加入有两个同时挂载的模态层。改为正文就近编号、界面统一展示来源；同一时刻只显示阅读或加入面板。
