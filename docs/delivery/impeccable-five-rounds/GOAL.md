# 五轮简化与动线优化目标

使用原项目 `skills/impeccable-design-polish/SKILL.md`，连续完成五轮“检查→修改→验证”。保留功能、全局技能源及项目软链接，不重做后端。以 OpenDesign 的 HomeHero、EntryNavRail、RecentProjectsStrip、SettingsDialog 的真实交互为参考。

验收：主导航仅保留日常场景；每页同一层级只有一个主要操作；低频管理和技术信息按需展开；中文查找/浏览→阅读→加入项目的路径无歧义；独立索引功能始终可达；没有只为减按钮而删除功能；键盘、状态反馈、全页动效与现有设计 token 保留。

1. 信息结构：审查所有页面与重复入口，收敛导航及低频管理。
2. 主要任务：简化首页结果、技能列表、发现/导入、项目使用链路。
3. 渐进披露：重新检查第二轮，整理维护/设置/备份/高级管理及按钮文案。
4. 状态与交互：检查第三轮成品，修复导航返回、重复操作、加载/空态/失败、键盘与窄窗口问题。
5. 最终复审：实际桌面走查，再修发现问题；构建、签名与交付。

每轮保留 findings、changes、checks，具体记录见 ROUNDS.md。五轮是顺序复审；独立页面范围可并行，但下一轮必须针对上一轮结果。
