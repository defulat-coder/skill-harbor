# 项目功能交付盘点

范围：`Workbench.tsx`（项目列表、项目详情、创建/添加向导、本地运行）、`ProjectDetail.tsx`（高级管理）、`AddProjectDialog.tsx`（旧入口）、`TaskOutput.tsx`。依据根/src AGENTS、docs/design、源 craft 字体、色彩、表单、状态、可访问性规则。公共鼠标动效由 Layout 继承，不添加页面监听。

## 产品语义

- 默认从全局技能库维护，再通过软链接加入项目；创建/添加向导固定 `symlink`。
- 项目移除登记调用原 `removeProject`；不删除磁盘项目目录。项目内移出技能是另一项操作，原有链接/本地文件提示保留。
- 本地运行仍调用现有 Codex 运行接口，沿用项目路径与模型配置，本轮不执行 CLI。
- 高级管理保留既有的本地技能、多工具变体、更新/回写逻辑，不能把原有差异覆盖成简单“已链接”。

## 可见差异与迁移边界

项目专属布局放 Workbench.module.css，使用共享token，未建立第二套颜色。高级管理原有状态/标签色保留语义，主题对比尚需实际截图复核。原生details用于诊断日志，本轮不增加无价值的高度动画。全部模态依赖共享DetailSheet的进入/退出/减少动效和焦点契约；没有页面级focus监听。

本盘点区分“检查源码”与“实际操作”。本代理未操作真实用户数据、未启动任务、未调用模型、未进行磁盘项目移除。涉及批量变体冲突、失败部分结果、CLI取消及日志需要隔离目录集成验收，不应仅凭源码判为全链路已验收。

### 实际运行等待反馈补充

TaskOutput 以当前运行 `created_at` 计算一分钟阈值；运行中且没有文字结果时，提示展开诊断日志、检查 CLI/连接，提供停止当前任务按钮。不会推断失败、自动停止、自动重试或显示假进度。已有文字结果始终优先展示。一次性定时器随卸载或运行状态切换清理；没有新增动画，减少动态效果环境同样显示静态说明。运行记录切换以 run ID 重挂载，避免沿用前一任务等待时间。TypeScript 和相关 ESLint 通过；真实任务等待场景由主代理验收。
